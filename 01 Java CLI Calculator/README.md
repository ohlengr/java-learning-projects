# Project 01 — Java CLI Calculator

A command-line calculator built while learning Core Java fundamentals.

## Concepts Learned

* Variables and primitive data types
* Scanner for user input
* Methods
* if/else
* switch
* while loop
* Formatted output

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal number support
* Division-by-zero handling
* Invalid operator handling
* Invalid number handling
* Repeat calculations
* Quit option (`q`)

## Project Structure

```text
01-cli-calculator/
└── src/
    └── Main.java
```

## Run

```bash
javac src/Main.java
java -cp src Main
```

## Learning Outcome

This project established the foundation for writing interactive Java console applications with clean method organization and basic error handling.
