# Project 02 — CLI Todo

A command-line Todo application built to learn Java's object-oriented programming fundamentals.

## Concepts Learned

* Classes and objects
* Constructors
* ArrayList
* Object references
* Menu-driven console applications
* CRUD operations
* Packages (later phase)

## Planned Features

* Add task
* List tasks
* Complete task
* Delete task

## Project Structure

```text
02-cli-todo/
└── src/
    └── Main.java
```

## Run

```bash
javac src/Main.java
java -cp src Main
```

## Learning Outcome

This project marks the transition from procedural Java programming into object-oriented thinking using custom classes and collections.
